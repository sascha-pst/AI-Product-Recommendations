Pickwise Sample products and review data, all fictional

Do shoppers trust other buyers or an AI reviewer?

Pickwise recommends earbuds two ways: from customer reviews, and from an AI that reads only the spec sheet. A Qualtrics experiment then tests whether people trust the picks themselves, or just the label on them.

Same shopper, different picks

Both engines choose from the same products within the shopper's budget, and their explanations are written by one shared template, so the wording never gives the source away.

The label test

Each participant sees one arm. Crossing where the picks came from with what they're labeled as separates trust in the content from trust in the label. Select an arm to see that participant's screen.

The two striped cells label picks with the wrong source. Those arms need ethics approval, and every participant learns the true source in the debrief.

How one session runs

Picks are generated ahead of time, so everyone in an arm sees exactly the same screen.

  1. Qualtrics assigns an armRandomizers set the arm and scenario, evenly across participants.
  2. The page shows three picksA Cloudflare Worker serves that arm's picks inside the survey.
  3. The choice goes backThe pick, its rank and time to decide return to Qualtrics.
  4. Data joins on response IDSurvey answers meet clicks and dwell time for analysis.
